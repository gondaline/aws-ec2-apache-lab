Um pouco do terminal

Exemplos de comandos para conferir o Apache em uma instância Amazon Linux.

ec2-user@amazon-linux:~
# Verificar se o Apache está funcionando
$ sudo systemctl status httpd

# Confirmar que o servidor responde por HTTP
$ curl -I http://localhost

# Reiniciar o servidor web
$ sudo systemctl restart httpd

# Conferir os arquivos publicados
$ ls /var/www/html/

systemctl consulta o status do serviço Apache ou controla sua execução.

curl -I faz uma requisição HTTP e exibe os cabeçalhos da resposta, permitindo conferir se o servidor está respondendo.
